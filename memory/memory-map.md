# Memory map

Index of the `memory/` store. Read this first every session.

| File | Holds | Update when |
|---|---|---|
| `memory-map.md` | This index. | You add or repurpose a memory file. |
| `terminology.md` | Domain vocabulary — the words the spec uses (intent, requirement, adapter, planner, dossier, evidence polarity, replay, BYOK, partial, search language vs UI locale). | A domain term is introduced, renamed, or its meaning shifts. |
| `summary.md` | Current project state — what is greenfield, what shipped this run, what is deferred. | A section lands, scope changes, or a deferral is resolved. |

Keep entries short and factual. Memory is for orientation, not documentation — the code and
`CLAUDE.md` are authoritative for how things work.
